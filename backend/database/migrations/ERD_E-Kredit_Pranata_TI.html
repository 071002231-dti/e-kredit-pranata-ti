Deskripsi Tabel

Core Tables (Tabel Utama)

users

Menyimpan data pegawai Pranata TI termasuk NIP, jabatan, golongan, dan tracking angka kredit.

  • id - Primary Key
  • nip - Nomor Induk Pegawai (unique, 18 digit)
  • name, email - Data identitas
  • role - user | verifier | admin
  • jenjang_jabatan - PTI Pelaksana/Pertama/Muda/Madya/Utama
  • golongan - II/a sampai IV/e
  • target_angka_kredit - Target kredit sesuai jenjang
  • current_credit_* - Kredit yang sudah didapat
  • banked_credit_* - Kredit yang di-tabung
  • compliance_percentage_* - Persentase kepatuhan 80/20

credit_schema

Master data kegiatan angka kredit berdasarkan Peraturan BKN No. 3 Tahun 2025.

  • id - Primary Key
  • category - Kategori utama kegiatan
  • subcategory - Sub kategori (nullable)
  • activity_name - Nama kegiatan
  • credit_points - Jumlah angka kredit (3 desimal)
  • satuan_hasil - Kali/Program/Dokumen/dll
  • batasan_penilaian - Batasan maksimal per tahun
  • pelaksana - Jenjang yang dapat melakukan
  • bukti_fisik - Jenis bukti yang diperlukan
  • unsur_type - utama (>=80%) | penunjang (<=20%)

activities

Pengajuan kegiatan angka kredit oleh pegawai.

  • id - Primary Key
  • user_id - FK ke users (pengaju)
  • schema_id - FK ke credit_schema
  • title - Judul kegiatan
  • description - Deskripsi detail
  • proof_file - Path file bukti
  • status - pending | approved | rejected
  • submitted_via - web | whatsapp
  • submitted_at - Waktu pengajuan

approvals

Riwayat persetujuan/penolakan oleh verifikator.

  • id - Primary Key
  • activity_id - FK ke activities
  • verifier_id - FK ke users (verifikator)
  • status - approved | rejected
  • comments - Catatan verifikator
  • approved_at - Waktu approval

Supporting Tables (Tabel Pendukung)

skp

Sasaran Kerja Pegawai - target tahunan angka kredit.

  • id - Primary Key
  • user_id - FK ke users
  • tahun - Tahun SKP
  • target_angka_kredit - Target kredit tahun ini
  • status - draft | submitted | approved | rejected
  • approved_by - FK ke users (approver)

skp_items

Detail item target per SKP.

  • id - Primary Key
  • skp_id - FK ke skp
  • schema_id - FK ke credit_schema
  • target_quantity - Target jumlah kegiatan
  • target_points - Target angka kredit
  • realisasi_quantity - Realisasi jumlah
  • realisasi_points - Realisasi kredit

credit_banks

Tabungan kredit yang belum bisa digunakan karena belum sesuai jenjang.

  • id - Primary Key
  • user_id - FK ke users
  • activity_id - FK ke activities
  • credit_schema_id - FK ke credit_schema
  • credit_points - Jumlah kredit disimpan
  • status - banked | unlocked | used
  • required_jenjang - Jenjang minimal untuk unlock
  • banked_at, unlocked_at, used_at - Tracking waktu

WhatsApp Integration Tables

whatsapp_users

Link antara user dengan nomor WhatsApp.

  • id - Primary Key
  • user_id - FK ke users (unique)
  • whatsapp_phone - Nomor WA (unique)
  • verified - Status verifikasi
  • notifications_enabled - Preferensi notifikasi

whatsapp_messages

Log semua pesan WhatsApp masuk dan keluar.

  • id - Primary Key
  • whatsapp_message_id - ID dari WhatsApp API
  • user_id - FK ke users (nullable)
  • from_number, to_number - Nomor telepon
  • direction - inbound | outbound
  • type - text | image | document | etc
  • status - sent | delivered | read | failed | pending

whatsapp_flows

Definisi WhatsApp Flow untuk form interaktif.

  • id - Primary Key
  • flow_id - ID Flow dari WA API
  • name - Nama flow
  • json_definition - Struktur JSON flow
  • status - draft | published | deprecated

whatsapp_sessions

Session percakapan WhatsApp untuk state management.

  • id - Primary Key
  • whatsapp_phone - Nomor WA
  • user_id - FK ke users (nullable)
  • state - Status percakapan saat ini
  • context - Data konteks (JSON)
  • expires_at - Waktu kadaluarsa session

System Tables (Tabel Sistem)

Session management untuk autentikasi web.

Token untuk reset password.

Catatan Teknis

  • Soft Delete: Tidak digunakan pada tabel utama - menggunakan status untuk tracking
  • Timestamps: Semua tabel memiliki created_at dan updated_at
  • Indexing: Index pada foreign key dan kolom yang sering di-query
  • Constraint: ON DELETE CASCADE untuk child tables, ON DELETE RESTRICT untuk referensi penting
  • Decimal Precision: credit_points menggunakan DECIMAL(10,3) untuk mendukung nilai seperti 0.147
  • Compliance Rule: Unsur utama harus >= 80%, unsur penunjang <= 20% dari total kredit
